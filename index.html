🏢 Dados da empresa

💾 Backup e restauração

Exporte todos os dados do sistema como um arquivo JSON para fazer backup ou migrar para outro navegador/dispositivo.

📦 Uso de armazenamento local

O navegador reserva um espaço limitado (geralmente 5–10 MB) para o armazenamento local de cada site — é isso que gera o erro "exceeded the quota" ao cadastrar muitos empreendimentos com fotos/documentos anexados. Não é um limite de quantidade de cadastros, e sim de tamanho total dos arquivos salvos localmente. Para cadastros verdadeiramente ilimitados, conecte o Supabase abaixo — lá os dados ficam no banco de dados na nuvem, sem esse limite do navegador.

Espaço utilizado (estimado) —

🌐 Conexão Supabase (sincronização em nuvem)

Configure para sincronizar os dados com o Supabase e acessar de qualquer dispositivo.

🗄️ Esquema SQL do banco de dados

Script completo (PostgreSQL / Supabase) com todas as tabelas usadas pelo sistema — usuários, empreendimentos, quadras, lotes, imóveis, clientes (com documentos), proprietários, corretores, reservas, vendas, locações, parcelas, comissões, documentos, contratos-modelo e auditoria. Execute no SQL Editor do Supabase (ou psql) para criar a estrutura antes de conectar a sincronização em nuvem.

💡 O campo documentos nas tabelas de clientes/imóveis pode ser mantido como JSONB (arquivos em base64) ou migrado futuramente para o Supabase Storage, referenciando apenas a URL do arquivo.
